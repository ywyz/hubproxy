本手册适用于 `ywyz/hubproxy` 的 `main` 分支。这个 fork 在上游的容器镜像和仓库文件代理基础上，增加了按白名单开放的 HTTPS 直链、Linux 软件包镜像入口和大文件下载登录。

## 下载方式

<CardGrid>
  <Card title="Docker 镜像" icon="seti:docker">
    从 Docker Hub、GHCR、Quay 等仓库拉取镜像，也可以在网页中搜索镜像、浏览标签并下载离线 tar 包。[Docker 镜像加速](./guides/docker-mirror/) · [离线镜像包](./guides/offline-images/)
  </Card>
  <Card title="GitHub 与 Hugging Face" icon="document">
    在原始 URL 前加上 HubProxy 地址，即可下载 Release 附件、Raw 文件和模型文件。支持的 Git 操作和 URL 格式见 [仓库文件代理指南](./guides/github-proxy/)。
  </Card>
  <Card title="Linux 软件包与 HTTPS 直链" icon="rocket">
    通过 `/mirrors/` 将软件包管理器连接到允许的上游，也可以按域名和路径开放其他 HTTPS 文件。仓库附带常用 Linux 软件源的白名单。[软件包镜像配置](./guides/package-mirrors/)
  </Card>
  <Card title="大文件下载" icon="approve-check">
    管理员配置本地下载账号后，浏览器用户可在 `/login` 登录，命令行客户端可使用 HTTP Basic 认证，下载超过匿名大小限制的文件。[传输特性与限制](./guides/capabilities/)
  </Card>
</CardGrid>

## 部署与配置

- 首次运行请从源码构建并检查服务状态。[快速开始](./getting-started/quick-start/)
- 调整端口、挂载配置或通过 HTTPS 对外提供服务。[Docker 部署](./deployment/docker/) · [反向代理](./deployment/reverse-proxy/)
- 设置下载大小、白名单和 IP 限流。[配置参考](./configuration/reference/)
