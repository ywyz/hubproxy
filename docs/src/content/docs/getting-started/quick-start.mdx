## 从源码启动

准备好 Git、Docker 和 Docker Compose，在准备存放源码的目录中运行以下命令。

```bash
git clone --branch main https://github.com/ywyz/hubproxy.git
cd hubproxy
docker compose up -d --build
```

仓库自带的 Compose 文件会构建 `hubproxy:local` 镜像，将主机的 `5000` 端口映射到容器，并以只读方式挂载 `src/config.toml`。默认配置已启用网页界面和常用 Linux 软件源。

## 验证服务

```bash
curl -fsS http://127.0.0.1:5000/ready
```

服务就绪后返回 HTTP 200，JSON 中包含 `"ready":true` 和 `"service":"hubproxy"`。此时可用浏览器打开 [本地首页](http://127.0.0.1:5000/)。还可以通过默认允许的 Debian 软件源验证一次上游请求。

```bash
curl -fsSI http://127.0.0.1:5000/mirrors/deb.debian.org/debian/dists/stable/InRelease
```

正常会返回 HTTP 200。若请求失败，可在仓库目录运行 `docker compose logs --tail=50 hubproxy` 查看日志。

## 调整部署

- **大文件下载。** 默认匿名单文件上限为 2 GiB。需要下载更大的文件时，配置 `HUBPROXY_DOWNLOAD_USERNAME` 和 `HUBPROXY_DOWNLOAD_PASSWORD`，再运行 `docker compose up -d` 使容器读取新值。浏览器用户可通过 `/login` 登录。[传输特性](../../guides/capabilities/) · [配置参考](../../configuration/reference/)
- **HTTPS 与镜像源。** 对外提供服务时可使用 Caddy 或 Nginx 终止 TLS。可在 `src/config.toml` 中调整允许使用的软件源。[Docker 部署](../../deployment/docker/) · [反向代理](../../deployment/reverse-proxy/) · [软件包镜像](../../guides/package-mirrors/)
- **上游系统包。** 安装脚本默认下载 `sky22333/hubproxy` 发布的 `.deb`、`.rpm` 或 `.apk`。使用上述源码构建即可部署本 fork 的功能。[系统安装说明](../install/)
