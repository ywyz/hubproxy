This guide covers the `main` branch of `ywyz/hubproxy`. The fork builds on the upstream container registry and repository file proxy with allowlisted HTTPS downloads, Linux package mirrors, and a local login for large downloads.

## What you can download

<CardGrid>
  <Card title="Container images" icon="seti:docker">
    Pull images from Docker Hub, GHCR, Quay, and other registries. The web interface also lets you search for images, browse tags, and export offline tar archives. [Docker mirror](./guides/docker-mirror/) · [Offline images](./guides/offline-images/)
  </Card>
  <Card title="GitHub and Hugging Face files" icon="document">
    Prefix an upstream URL with your HubProxy address to fetch release assets, raw files, and model files. The [repository proxy guide](./guides/github-proxy/) covers supported Git operations and URL formats.
  </Card>
  <Card title="Linux packages and HTTPS files" icon="rocket">
    Point your package manager at an allowed upstream through `/mirrors/`, or allow another HTTPS file by host and path. The checkout includes rules for common Linux package repositories. [Package mirror setup](./guides/package-mirrors/)
  </Card>
  <Card title="Large downloads" icon="approve-check">
    Once the administrator configures a local account, users can sign in at `/login` or use HTTP Basic authentication in a client to download files above the anonymous size limit. [Transfer capabilities and limits](./guides/capabilities/)
  </Card>
</CardGrid>

## Deployment and configuration

- Build from source and check the running service. [Quick start](./getting-started/quick-start/)
- Configure ports, mount a configuration file, or serve HubProxy over HTTPS. [Docker deployment](./deployment/docker/) · [Reverse proxy](./deployment/reverse-proxy/)
- Set download limits, allowlists, and per-IP rate limits. [Configuration reference](./configuration/reference/)
